# Dropshipper

Equipo de agentes de IA para dropshipping COD en Colombia: ventas por WhatsApp, pedidos en Dropi,
productos ganadores con DropKiller, finanzas, campañas en Meta y landings, con aprobación humana de un clic.

- 📄 Propuesta completa: [`docs/PROPUESTA.md`](docs/PROPUESTA.md)
- 🧠 Motor de agentes: núcleo [`arxi`](https://github.com/michiTrader/arxi-tui) (`host/v1`)
- 🤖 LLM: DeepSeek

Estado: **propuesta / diseño** (Fase 0 pendiente).
